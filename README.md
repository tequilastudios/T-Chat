## From company knowledge to real work

T-Chat brings conversations, documents, models, agents and automations into one operational environment. Choose which workflows stay local and which external services to enable.

| Capability | What it brings to your team |
| --- | --- |
| **Second Brain** | Selected document collections, Markdown support, source references and refreshed context in existing chats. AI-proposed additions require confirmation. |
| **Projects and Workspace** | Organised files and folders, verified file writes and synchronisation that protects unsaved edits. Local application workflows include Python and databases. |
| **Agents and meetings** | Personalities, missions and multi-agent meetings with configurable tools, permissions and confirmations. |
| **Local and hybrid models** | Ollama, MLX and llama.cpp workflows, with API services when enabled. Memory management adapts to the machine and coordinates heavy local inference during meetings. |
| **Connected work** | Supported email, calendar and other Office accounts, with explicit permissions and selected imports into Second Brain. |
| **Companion and Nearby** | Local runtime and model management, visible Hugging Face download progress and access from authorised devices on the configured network. |

**Current product release: 4.6.5.** File-save verification confirms the operation, not the accuracy of generated content. Human review remains part of operational use.

## Who it is for

- **Businesses and teams:** internal knowledge, document workflows and repeatable tasks, starting with a measurable pilot.
- **Institutions and public bodies:** staff support using approved sources, defined responsibilities and reviewed results.
- **Developers, facility managers and integrators:** pilots for a dedicated AI information node serving a building, campus or operational site.

A building node is a project to design and validate with the operator. T-Chat supplies the software platform; enclosure, power, networking, capacity and maintenance require separate assessment. It is not a certified emergency device or building-control system.

## Deployment and scope

The current edition supports **Mac Apple Silicon**, with browser access through the configured deployment. Model size, context, available memory and concurrent work determine capacity. NVIDIA and AMD editions are in development; availability is not yet announced.

Local features can run without Internet when models, runtimes and documents are prepared and the **licence remains valid within its permitted offline window**. Activation, renewals, power and recovery need planning. External APIs and online integrations require connectivity and may transmit the data needed by the selected service.

Local installation does not by itself establish regulatory compliance, a security certification or public procurement qualification. Requirements should be assessed within the project.

## Italiano

### L’AI della tua organizzazione. Nel tuo perimetro.

T-Chat riunisce conversazioni, documenti, modelli, agenti e automazioni in un unico ambiente operativo. È pensato per aziende e istituzioni che vogliono scegliere dove vengono elaborate le informazioni e come lavorano gli agenti.

- **Second Brain:** fonti selezionate, file Markdown, riferimenti e contesto aggiornato anche nelle chat esistenti. Le aggiunte proposte dall’AI richiedono conferma.
- **Progetti e Workspace:** file e cartelle organizzati, scritture verificate e protezione delle modifiche non salvate. Applicazioni locali anche con Python e database.
- **Agenti e riunioni:** personalità, missioni e automazioni con strumenti e conferme configurabili. La memoria viene gestita in base alla macchina e al carico.
- **Modelli e Companion:** Ollama, MLX, llama.cpp e API abilitate; gestione dei runtime e avanzamento dei download Hugging Face. Nearby permette l’accesso dai dispositivi autorizzati nella rete prevista.
- **Edifici e infrastrutture:** un nodo AI dedicato per consultare la conoscenza operativa dell’immobile, da valutare con costruttori, gestori e integratori attraverso un progetto pilota.

La versione attuale è la **4.6.5 per Mac Apple Silicon**. L’uso offline richiede risorse già predisposte e una licenza valida entro la finestra prevista. Servizi online, capacità simultanea, alimentazione e ripristino vanno pianificati. Un nodo per rifugi o siti isolati è un supporto informativo da validare: non sostituisce procedure, personale qualificato o comunicazioni ufficiali.
